# Alpha Portfolio — 02 스코어링 설계 v0.1

> **목적**  
> Q/V/SR/R 팩터 점수, 복합 점수, 등급(A/B/C/Reject), Role·Tier 분류 규칙을 **수식·YAML·출력**까지 고정한다.  
> 입력 스키마: `01_데이터_스키마.md` · 개념·한도: `00_개념정집.md` v0.2

---

## 0. 파이프라인

```text
kospi_universe + price_snapshot + fundamentals [+ shareholder]
        ↓
   [Gate] universe_gate.yaml
        ↓
   screening_universe.csv (gate_pass=true)
        ↓
   [Score] Q / V / SR / R  (+ M for Satellite track)
        ↓
   composite_score + grade
        ↓
   role_suggested + tier (Core / Satellite)
        ↓
   alpha_scores.csv → alpha_candidates.csv
```

**P0 전제**

- `fundamentals.verified = true` 아니면 스코어링 제외 (grade=Reject, data_gate=RED)
- `shareholder.csv` 없으면 SR=50 (중립), data_gate=YELLOW
- `kr_alpha_weight`는 스코어링 입력이 **아님** — 후보 `portfolio_weight_suggested` 산출 시에만 주입

## 1. Gate (선행 필터)

Gate 통과 전에는 점수 계산하지 않는다. 임계값은 `config/universe_gate.yaml`.

| ID | 조건 | fail_reason |
|----|------|-------------|
| G01 | `is_etf` or `is_spac` | `etf_spac` |
| G02 | `is_managed` or `is_halted` | `managed_halted` |
| G03 | `market_cap` < 3,000억 | `low_market_cap` |
| G04 | `avg_trading_value_20d` < 10억 | `low_liquidity` |
| G05 | `net_income_2y` 2년 연속 < 0 | `consecutive_loss` |
| G06 | `debt_ratio` > 200% AND NOT `is_financial` | `high_debt` |
| G07 | `audit_opinion` != `unqualified` | `audit_issue` |
| G08 | `fundamentals.verified` != true | `unverified` |

## 2. 점수 체계 공통

### 2.1 정규화

모든 서브 점수는 **0~100**으로 변환한다.

```text
percentile_score(x, peer_group) =
  rank_pct(x, peer_group) × 100        # peer_group 내 백분위
  # 동률: average rank
  # peer_group = 동일 sector (fundamentals.sector)
  # sector 표본 < 5 → market 전체로 fallback
```

```text
linear_score(x, low, high, invert=false) =
  clamp((x - low) / (high - low) × 100, 0, 100)
  if invert: 100 - linear_score(...)
```

최종 팩터 점수 = 서브 점수의 **가중 평균** (YAML `sub_weights`).

### 2.2 결측 처리

| 상황 | 처리 |
|------|------|
| PER/PBR/ev_ebitda 중 1개 결측 | 나머지로 재가중 |
| SR 전체 결측 | SR=50, YELLOW |
| `return_6m` 결측 | Satellite track 불가 → Core track만 |
| sector 표본 < 5 | market percentile |

## 3. Q — Quality (35%)

**가설**: ROE·수익성·부채 건전성·이익 안정 → 장기 초과수익

| 서브 | 입력 | 계산 | 가중 |
|------|------|------|------|
| Q1 ROE | `roe_3y_avg` or `roe` | `linear_score(roe, 5, 20)` | 0.40 |
| Q2 OPM | `opm` | `percentile_score(opm, sector)` | 0.25 |
| Q3 부채 | `debt_ratio` | `linear_score(debt_ratio, 200, 50, invert=true)` · financial→50 | 0.20 |
| Q4 이익 안정 | derived | 아래 | 0.15 |

**Q4 이익 안정 (derived)**

```text
if net_income_2y > 0 for both years: 85
elif one year loss:                   40
else:                                 0  → Gate G05에서 이미 제외
```

**지주/금융 예외**

- `is_financial=true`: Q3=50 (중립), 부채 Gate G06 면제
- `is_holding=true`: Q1 가중 0.30, Q2 0.20, Q3 0.10, Q4 0.40 (NAV·배당 안정 강조)

```text
score_q = Σ(sub_i × weight_i)
```

---

## 4. V — Value (30%)

**가설**: 섹터 **상대** 저평가 → mean reversion + 밸류트랩 회피는 Q·Gate로

| 서브 | 입력 | 계산 | 가중 |
|------|------|------|------|
| V1 PER | `per`, `sector_per_median` | `percentile_score(per/sector_per_median, sector, invert=true)` | 0.35 |
| V2 PBR | `pbr`, `sector_pbr_median` | 동일 | 0.35 |
| V3 EV/EBITDA | `ev_ebitda` | `percentile_score(ev_ebitda, sector, invert=true)` · 결측 시 제외 | 0.15 |
| V4 FCF Yield | `fcf_yield` | `linear_score(fcf_yield, 0, 8)` | 0.15 |

**PER/PBR ratio 해석**

- ratio < 1 → 섹터 중위보다 저평가 → 높은 점수
- PER ≤ 0 or PBR ≤ 0 → V1/V2=0 (적자·자본잠식)

**지주 (`is_holding=true`)**

- V2 가중 0.55, V1 0.15, V3 0.15, V4 0.15
- PBR/NAV 디스카운트 중심

```text
score_v = Σ(sub_i × weight_i)
```

---

## 5. SR — Shareholder Return (25%)

**가설**: 배당·자사주 → 주주 친화 + 하방 지지

| 서브 | 입력 | 계산 | 가중 |
|------|------|------|------|
| SR1 배당수익률 | `dividend_yield` | `linear_score(dividend_yield, 1, 5)` | 0.50 |
| SR2 배당성향 | `payout_ratio` | `linear_score(payout_ratio, 10, 60)` · >80%→40 cap | 0.25 |
| SR3 자사주 | `buyback_3y` | true→80, false→30 | 0.25 |

`shareholder.csv` 없음 → **score_sr = 50** (중립)

```text
score_sr = Σ(sub_i × weight_i)
```

---

## 6. R — Risk (10%)

**가설**: 변동성·낙폭 억제 → KOSPI 200 대비 안정적 알파

| 서브 | 입력 | 계산 | 가중 |
|------|------|------|------|
| R1 변동성 | `volatility_1y` | `linear_score(vol, 15, 45, invert=true)` | 0.50 |
| R2 52주 위치 | `close`, `high_52w`, `low_52w` | `(close-low)/(high-low)×100` · >95→30 cap | 0.30 |
| R3 베타 | `beta_kospi200` | `linear_score(abs(beta-1), 0, 0.8, invert=true)` · P0 결측→50 | 0.20 |

```text
score_r = Σ(sub_i × weight_i)
```

---

## 7. M — Momentum (Satellite 전용, Core 미포함)

Core 복합 점수에는 **M 가중 0**. Satellite track 판정·B등급 보조용.

| 서브 | 입력 | 계산 |
|------|------|------|
| M1 6M 수익률 | `return_6m` | `percentile_score(return_6m, market)` |
| M2 52주 고점 | `close/high_52w` | ratio ≥ 0.85 → 가점, < 0.70 → 감점 |

```text
score_m = 0.60 × M1 + 0.40 × M2
```

**Satellite track 진입 조건** (AND)

- `score_m` ≥ 60
- `return_6m` > 0
- Gate 통과

## 8. 복합 점수 (Composite)

### 8.1 Core track

```text
composite_core =
  0.35 × score_q +
  0.30 × score_v +
  0.25 × score_sr +
  0.10 × score_r
```

### 8.2 Satellite track

Satellite track 진입 시:

```text
composite_satellite =
  0.30 × score_q +
  0.20 × score_v +
  0.15 × score_sr +
  0.10 × score_r +
  0.25 × score_m
```

**최종 composite**: 두 track 중 **높은 쪽** 채택, `tier` 기록.

### 8.3 보유 가점 (Incumbent)

```text
if is_held:
  composite_final = min(composite + 3, 100)
  incumbent_bonus = 3
else:
  composite_final = composite
  incumbent_bonus = 0
```

퇴출 Hard/Soft 발동 시 incumbent_bonus **무효** (03_퇴출_규칙.md).

## 9. 등급 (Grade)

| 등급 | composite_final | 추가 조건 |
|------|-----------------|-----------|
| **A** | ≥ 70 | score_q ≥ 55 AND score_v ≥ 50 |
| **B** | 55 ~ 69 | Satellite: score_m ≥ 60 추가 |
| **C** | 45 ~ 54 | Watch only, 매수 없음 |
| **Reject** | < 45 | 또는 Gate fail |

**강등 규칙**

| 조건 | 결과 |
|------|------|
| score_q < 40 | A→B, B→C |
| score_v < 35 AND score_q < 50 | 1등급 강등 (밸류트랩 의심) |
| data_gate=RED | Reject |

## 10. Role 분류

Role은 **재무 패턴 + 점수**로 결정. `config/alpha_scoring.yaml` → `role_rules`.

### 10.1 우선순위 (first match)

| 순위 | role | 조건 |
|------|------|------|
| 1 | `momentum_satellite` | tier=Satellite AND score_m ≥ 65 |
| 2 | `cyclical_value` | sector ∈ {materials, industrial, energy} AND score_v ≥ 60 AND tier=Satellite |
| 3 | `shareholder_return` | score_sr ≥ 70 AND dividend_yield ≥ 2.5 |
| 4 | `quality_dividend` | score_sr ≥ 65 AND score_q ≥ 65 AND sector ∈ {telecom, utility} |
| 5 | `quality_defensive` | score_q ≥ 65 AND sector ∈ {consumer, healthcare} |
| 6 | `defensive_consumer` | score_q ≥ 60 AND opm ≥ sector median |
| 7 | `dividend_value` | score_sr ≥ 60 AND score_v ≥ 60 |
| 8 | `value_rerating` | score_v ≥ 65 AND is_holding=true |
| 9 | `value_quality` | score_q ≥ 55 AND score_v ≥ 55 |
| 10 | `value_defensive` | score_v ≥ 60 AND score_q ≥ 50 |
| default | `value_quality` | — |

### 10.2 Tier

| tier | 조건 |
|------|------|
| **Core** | grade A, OR (grade B AND NOT Satellite track) |
| **Satellite** | Satellite track AND grade ≥ B |
| **—** | grade C / Reject |

## 11. 섹터·Role 집중도 (후보 출력 시)

스코어링 후 `alpha_candidates.csv` 생성 시 적용:

| 한도 | 값 | 동작 |
|------|-----|------|
| 동일 sector 후보 | 상위 5개까지 | 초과 시 rank↓ |
| `momentum_satellite` | 슬리브 내 합 ≤ 25% | weight cap |
| `cyclical_value` | 단일 ≤ 5% sleeve | weight cap |
| Core role (동일) | 3종목 초과 시 | 신규 후보 rank↓ |

> 절대 `kr_alpha_weight` 고정 없음. sleeve cap만 적용.

## 12. sleeve_weight_suggested (초안)

**A등급 Core**

```text
base = 4.0  # sleeve % (슬리브 내부)
adjust = (composite_final - 70) / 30 × 2.0   # 70~100 → 0~+2%p
sleeve_weight = min(base + adjust, 8.0)      # 단일 Core cap 8% sleeve
```

**B등급 Satellite**

```text
sleeve_weight = min(3.0 + (composite_final - 55) / 14 × 2.0, 5.0)  # max 5% sleeve
```

**예외 8%**: §개념정집 1.3 조건 YAML `satellite_exception` 전부 충족

```text
portfolio_weight_suggested = kr_alpha_weight × sleeve_weight / 100
# kr_alpha_weight: 실행 시 상위 시스템에서 주입 (예: compass_regime.json)
```

## 13. YAML 설정

구현 시 `config/alpha_scoring.yaml` 사용. 스키마:

```yaml
version: "0.1"
composite_weights:
  core:    { q: 0.35, v: 0.30, sr: 0.25, r: 0.10, m: 0.00 }
  satellite: { q: 0.30, v: 0.20, sr: 0.15, r: 0.10, m: 0.25 }

grades:
  A: { min_composite: 70, min_q: 55, min_v: 50 }
  B: { min_composite: 55, satellite_min_m: 60 }
  C: { min_composite: 45 }

incumbent_bonus: 3

satellite_track:
  min_score_m: 60
  min_return_6m: 0

role_rules: [...]   # §10.1
sector_caps: [...]  # §11
```

실제 파일: `alpha_portfolio/config/alpha_scoring.yaml`
