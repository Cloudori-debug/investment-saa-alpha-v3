# Alpha Portfolio — 03 퇴출 규칙 v0.1

> **목적**  
> 보유 `kr_alpha` 종목의 **Hold / Trim / Replace / Park** 판단을 규칙으로 고정한다.  
> 입력: `alpha_scores.csv` + `positions.csv` + `fundamentals.csv` + (선택) `price_snapshot.csv`  
> 설정: `config/alpha_exit_rules.yaml`  
> 출력: `alpha_exit_review.csv`

연동: `00_개념정집` v0.2 · `02_스코어링_설계` · 상위 Trigger/Execution

---

## 0. 파이프라인

```text
보유 kr_alpha (positions.csv)
        ↓
alpha_scores (재계산 또는 캐시)
        ↓
[1] Hard Exit 검사 (즉시 Replace)
        ↓
[2] Soft Exit 검사 (Trim → Replace)
        ↓
[3] Role / Tier Exit (Satellite 우선)
        ↓
[4] Park 적격성 (target=0 전환 대기)
        ↓
[5] Park 재심사 (30/60/90일)
        ↓
alpha_exit_review.csv → trade_actions (상위)
```

**원칙**

- 퇴출 판단은 **스코어·Gate·role** 기반. 감정·손실 회피는 Park 허용 사유가 **아님**.
- Hard Exit 발동 시 **incumbent +3 무효**, `Replace` 우선.
- `kr_alpha_weight` 축소는 **상위 TAA** — Alpha는 종목 단위 Trim/Replace만 제안.

---

## 1. Exit 유형 정의

| 유형 | 의미 | action_suggested | incumbent +3 |
|------|------|------------------|:------------:|
| **None** | 유지 | `Hold` | 유지 |
| **Soft** | 점진 축소·교체 검토 | `Trim` → `Replace` | **무효** |
| **Hard** | 즉시 교체 | `Replace` | **무효** |
| **Park** | target=0, 최대 3개월 관망 | `Park` | **무효** |

**우선순위** (동시 충족 시): Hard > Soft > Role Exit > Park

---

## 2. Hard Exit

**즉시 `Replace`**. Park 불가.

| ID | 조건 | exit_reason 코드 |
|----|------|------------------|
| H01 | Gate G02: 관리종목·거래정지 | `managed_halted` |
| H02 | Gate G07: 감사의견 한정 이외 | `audit_issue` |
| H03 | Gate G05: 2년 연속 적자 (보유 중 악화) | `consecutive_loss` |
| H04 | Gate G06: 부채비율 > 200% (금융 제외) | `high_debt` |
| H05 | `grade` = Reject **2주 연속** (주간 배치 기준) | `reject_2w` |
| H06 | `fundamentals.verified` = false | `unverified` |
| H07 | 회계·지배구조 RED 플래그 (`stock_flags.csv`) | `governance_red` |
| H08 | Satellite: `score_m` < 40 AND `return_6m` < -15% | `satellite_momentum_collapse` |

---

## 3. Soft Exit

**1차 `Trim`**, 2주 후에도 조건 유지 시 `Replace`.

| ID | 조건 | exit_reason |
|----|------|-------------|
| S01 | `composite_score` < 45 (incumbent **제외** 후) | `low_composite` |
| S02 | `grade` = C **2주 연속** | `grade_c_2w` |
| S03 | `score_q` < 40 AND `score_v` < 35 (밸류트랩) | `value_trap` |
| S04 | KOSPI 200 대비 **3개월** underperform > 10%p | `rel_underperform_3m` |
| S05 | 목표 대비 overweight +5%p (전체 포트) | `overweight` |
| S06 | Core → Satellite track 전환 + `score_m` < 55 | `core_to_satellite_weak` |
| S07 | `role` 변경 + 신규 role이 Watch/Reject 등급 | `role_downgrade` |

**Soft → Replace 승격**

```text
if soft_exit_active for >= 14 calendar days AND condition still true:
  action_suggested = Replace
```

---

## 4. Role / Tier Exit

Satellite는 Core보다 **퇴출 기준 엄격**.

### 4.1 Satellite (`tier` = Satellite)

| ID | 조건 | action |
|----|------|--------|
| T01 | `score_m` < 50 | Trim |
| T02 | `return_6m` < 0 AND `score_m` < 55 | Trim → Replace |
| T03 | `role` = momentum_satellite AND 52w 고점 대비 -20% | Replace |
| T04 | `cyclical_value` AND sector Risk-off (상위 레짐 CAUTION+) | Trim |

단일 Satellite **슬리브 내 5%** 초과 시 S05(overweight)와 동일 Trim.

### 4.2 Core (`tier` = Core)

| ID | 조건 | action |
|----|------|--------|
| T10 | `grade` A→B AND `composite` (no bonus) < 60 | Hold, Watch |
| T11 | `grade` B→C | Soft (S02) |
| T12 | 투자 논리 role 유지 + `score_q` ≥ 50 | Hold 우선 |

Core는 **급 Replace 금지** — Soft 2주 경과 후에만 Replace (Hard 제외).

---

## 5. Park 규칙

### 5.1 정의

Park = 목표 매트릭스에서 **제외**(`target_weight=0`)했으나 **즉시 매도하지 않고** 검토 기간을 두는 상태.

**허용**

| 사유 코드 | 설명 |
|-----------|------|
| `tax_lot` | 세금·체결 구간상 즉시 매도 불리 |
| `temp_earnings` | 일시적 실적 훼손 (1회성) |

**불허** → Hard/Soft Exit

| 사유 | 처리 |
|------|------|
| 손실 확정 회피 | Soft S01 |
| 투자 논리 훼손 | Soft/Replace |
| 회계·유동성 | Hard |

### 5.2 기간

| 항목 | 값 |
|------|-----|
| 최대 관망 | **90일** (`park.max_months: 3`) |
| 재심사 | **30 / 60 / 90일** |

| 경과 | 필수 행동 |
|------|-----------|
| 30일 | 원인·재무 재검토, `park_reason` 갱신 |
| 60일 | 대체 후보(`alpha_candidates`)와 비교 |
| 90일 | **Hold / Trim / Replace 중 하나 강제** — Park 연장 불가 |

### 5.3 Park 상태 필드

| 필드 | 설명 |
|------|------|
| `park_start_date` | Park 시작일 |
| `park_days` | `as_of - park_start_date` |
| `park_review_due` | 다음 재심사일 |
| `park_reason` | `tax_lot` / `temp_earnings` |

Park 중에도 **Hard Exit 조건** 발생 시 즉시 Replace.

---

## 6. Incumbent Bonus 무효

`02_스코어링_설계` §8.3: 보유 +3점.

**무효 조건** (재스코어링 시 `incumbent_bonus=0`, composite 재계산):

- Hard Exit **후보** (H01~H08 중 하나라도 true)
- Soft Exit **활성** (S01~S07)
- Park **활성**
- Role/Tier Exit Trim/Replace 권고

```text
if exit_type in (Soft, Hard, Park) OR tier_exit triggers trim/replace:
  composite_final = composite_raw   # +3 제거
  recompute grade
```

## 7. 상위 레짐 연동 (참조)

Alpha Exit은 **종목 단위**. 슬리브 총량은 상위 TAA.

| 상위 레짐 | Alpha Exit 추가 규칙 |
|-----------|------------------------|
| YELLOW_STABLE | 기본 규칙 |
| CAUTION | Satellite **신규 유지** Hold, Soft Trim 가속 |
| RISK_OFF | Satellite T01~T04 우선 Trim, Core Soft만 |
| CRISIS | Hard만 즉시, 나머지 Hold·Park 금지 신규 |

입력: `compass_regime.json` 또는 `market_indicators.regime` (P0 선택).
