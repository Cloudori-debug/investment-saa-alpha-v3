# Alpha Portfolio — 01 데이터 스키마 v0.1

> **목적**  
> 알파 스크리닝·스코어링·퇴출에 필요한 **입력 CSV 컬럼**을 P0 기준으로 고정한다.  
> 이 문서는 **데이터 수집 MVP**의 범위 경계를 함께 정의한다.

---

## 0. 경계 고정

### 0.1 Alpha ↔ Data Collection

| | Alpha Portfolio | Data Collection MVP |
|--|-----------------|---------------------|
| **질문** | 어떤 컬럼으로 점수·role·퇴출을 판단할 것인가 | 그 컬럼을 **어떻게 채울 것인가** |
| **P0** | 스키마 + 검증 규칙 | **PyKRX 자동** + **재무 수동 CSV** |
| **성공** | 스키마 100% 준수 | `data/raw/` 필수 파일 존재 + Gate 통과 |

### 0.2 P0 자동 vs 수동

| 데이터 | P0 | P1 | P2 |
|--------|----|----|-----|
| 종목 마스터 (코드·이름·시장) | PyKRX | PyKRX | PyKRX |
| 일별 가격·거래대금·시총 | **PyKRX** | PyKRX | PyKRX |
| ROE·PER·PBR·부채비율 등 | **수동 CSV** | — | OpenDART |
| 배당·자사주 | **수동 CSV** (후순위) | — | OpenDART |
| 관리종목·거래정지 | PyKRX + 수동 플래그 | PyKRX | PyKRX |

### 0.3 디렉터리 구조

```text
alpha_portfolio/
├── data/
│   ├── raw/                    # 원본·수집 결과
│   │   ├── kospi_universe.csv
│   │   ├── price_daily.csv
│   │   ├── price_snapshot.csv  # P0 스크리닝용 최신 스냅샷
│   │   ├── fundamentals.csv    # P0 수동
│   │   └── shareholder.csv     # P0 수동 (선택)
│   ├── input/                  # 검증 통과·스크리너 입력
│   │   └── screening_universe.csv
│   └── output/                 # 스크리너 결과
│       ├── alpha_scores.csv
│       └── alpha_candidates.csv
├── config/
│   └── universe_gate.yaml      # Gate 임계값
└── docs/
```

## 1. kospi_universe.csv

**역할**: 발굴 유니버스 마스터  
**P0 수집**: PyKRX (KOSPI + KOSDAQ)

| 컬럼 | 타입 | 필수 | 설명 |
|------|------|:----:|------|
| `ticker` | str | ✅ | 6자리 종목코드 (zero-pad) |
| `name` | str | ✅ | 종목명 |
| `market` | str | ✅ | `KOSPI` / `KOSDAQ` |
| `sector` | str | | 업종 (KRX/WICS 또는 수동) |
| `listing_date` | date | | 상장일 `YYYY-MM-DD` |
| `is_etf` | bool | ✅ | ETF/ETN 여부 — `true`면 알파 제외 |
| `is_spac` | bool | | SPAC 여부 |
| `is_managed` | bool | | 관리종목 |
| `is_halted` | bool | | 거래정지 |
| `as_of` | date | ✅ | 스냅샷 기준일 |

**Gate에서 제외**: `is_etf=true`, `is_spac=true`, `is_managed=true`, `is_halted=true`

**예시**

```csv
ticker,name,market,sector,listing_date,is_etf,is_spac,is_managed,is_halted,as_of
021240,코웨이,KOSPI,consumer,2013-10-22,false,false,false,false,2026-06-17
069500,KODEX 200,KOSPI,equity,2002-10-14,true,false,false,false,2026-06-17
```

## 4. fundamentals.csv

**역할**: Q/V 팩터 입력 — **P0 핵심 수동 파일**  
**P0 수집**: 사용자 입력 또는 스프레드시트 export  
**P2**: OpenDART 자동 (계정 매핑 후)

| 컬럼 | 타입 | 필수 | Q/V/SR | 설명 |
|------|------|:----:|--------|------|
| `ticker` | str | ✅ | | |
| `as_of` | date | ✅ | | 재무 기준일 (결산기) |
| `fiscal_year` | int | ✅ | | 사업연도 |
| `sector` | str | | | 섹터 (상대 밸류 비교) |
| `roe` | float | ✅ | Q | ROE % (3년 평균은 derived) |
| `roe_3y_avg` | float | | Q | 3년 평균 ROE |
| `opm` | float | | Q | 영업이익률 % |
| `debt_ratio` | float | ✅ | Q | 부채비율 % (금융·지주 예외 플래그) |
| `is_financial` | bool | | | 금융업 — 부채비율 Gate 예외 |
| `is_holding` | bool | | | 지주 — PBR/NAV 별도 |
| `per` | float | ✅ | V | PER |
| `pbr` | float | ✅ | V | PBR |
| `ev_ebitda` | float | | V | EV/EBITDA |
| `fcf_yield` | float | | V | FCF Yield |
| `sector_per_median` | float | | V | 섹터 PER 중위 (없으면 derived) |
| `sector_pbr_median` | float | | V | 섹터 PBR 중위 |
| `net_income_2y` | float | | Q Gate | 최근 2년 당기순이익 (적자 Gate) |
| `audit_opinion` | str | | Gate | `unqualified` / `qualified` / `adverse` |
| `verified` | bool | ✅ | | **수동 검증 완료** (P0 필수) |
| `verified_by` | str | | | 검증자·출처 메모 |
| `source` | str | | | `manual` / `dart` / `fnguide` |

**Gate 규칙**

| 규칙 | 조건 |
|------|------|
| 연속 적자 | `net_income_2y` 2년 모두 < 0 → 제외 |
| 부채 | `debt_ratio` > 200% AND NOT `is_financial` → 제외 |
| 감사 | `audit_opinion` != `unqualified` → 제외 |
| P0 검증 | `verified` != true → 스코어링 제외 (Watch only) |

**예시**

```csv
ticker,as_of,fiscal_year,sector,roe,opm,debt_ratio,is_financial,is_holding,per,pbr,ev_ebitda,fcf_yield,audit_opinion,verified,source
021240,2026-06-17,2025,consumer,18.2,14.1,45.3,false,false,12.4,1.8,8.2,4.1,unqualified,true,manual
005830,2026-06-17,2025,insurance,12.1,9.8,0,false,false,8.5,0.9,,,unqualified,true,manual
```

## 10. 상위 시스템 연동 파일 (기존 유지)

Alpha Portfolio는 아래 파일을 **읽기/쓰기** 연동한다. 스키마 변경 없음.

| 파일 | 위치 | Alpha 사용 |
|------|------|------------|
| `positions.csv` | `data/raw/` | 보유·`is_held` |
| `target_portfolio.csv` | `data/raw/` | `portfolio_weight` 목표 |
| `portfolio_policy.yaml` | 상위 | 단일종목·kr_alpha HARD |

**target_portfolio.csv (kr_alpha 행)**

```csv
ticker,name,asset_group,sector,role,target_weight,min_weight,max_weight
021240,코웨이,kr_alpha,consumer,quality_defensive,4,2,6
```

- `target_weight` = **전체 포트 %** (슬리브 총량 × sleeve 내부 비중과 일치해야 함)

## 11. config/universe_gate.yaml

```yaml
# P0 Gate — 02_스코어링_설계.md와 동기화
gate:
  market_cap_min: 300000000000      # 3,000억
  avg_trading_value_20d_min: 1000000000  # 10억
  debt_ratio_max: 200               # %, is_financial=false
  consecutive_loss_years: 2

benchmark:
  primary: KOSPI200
  secondary: KOSPI

satellite:
  sleeve_max_pct: 25                # kr_alpha 슬리브 내부
  single_name_max_pct: 5
  single_name_exception_max_pct: 8

park:
  max_months: 3
  review_days: [30, 60, 90]

data:
  p0_auto: [kospi_universe, price_snapshot]
  p0_manual: [fundamentals, shareholder]
  require_verified: true
```

## 13. PyKRX P0 수집 범위 (구현 예정)

| 함수/대상 | 출력 컬럼 |
|-----------|-----------|
| `StockListing(KOSPI/KOSDAQ)` | universe 마스터 |
| `get_market_cap_by_date` | `market_cap` |
| `get_market_ohlcv_by_date` | `close`, `volume`, `trading_value` |
| rolling 20d | `avg_trading_value_20d` |
| rolling 126d | `return_6m` |

**P0 PyKRX 하지 않음**: ROE, PER, PBR, 배당 → `fundamentals.csv` / `shareholder.csv`

## 14. 검증 규칙 (validators)

| 검사 | 규칙 |
|------|------|
| ticker 형식 | 6자리 zero-pad |
| 중복 | `ticker` + `as_of` unique (snapshot/fundamentals) |
| ETF in alpha | `is_etf=true` → screening_universe 제외 |
| verified | P0 스코어링: fundamentals 미검증 → RED |
| weight 합 | target kr_alpha 행 합 ≈ `kr_alpha_weight` (상위 검증) |
