# Alpha Portfolio — 04 목표매트릭스 가이드 v0.1

> **목적**  
> 스크리너·퇴출 결과를 **`target_portfolio.csv` 초안**으로 변환하는 규칙을 고정한다.  
> 초안은 **자동 생성 · 사람 승인 · 상위 시스템 반영** 순서를 따른다.

연동: `00_개념정집` v0.2 · `02_스코어링` · `03_퇴출` · `config/target_matrix.yaml`

| 항목 | Alpha Portfolio | 상위 시스템 |
|------|-----------------|-------------|
| `kr_alpha_weight` | **입력** (고정 안 함) | SAA/TAA 산출 |

---

## 1. 비중 단위 (재확인)

```text
portfolio_weight = kr_alpha_weight × sleeve_weight / 100
```

| 단위 | 예 (kr_alpha=31%) | 파일 |
|------|-------------------|------|
| sleeve 4% | portfolio **1.24%** | `sleeve_weight` in draft |
| portfolio 4.82% | sleeve **~15.5%** | `target_portfolio.csv` |

**`target_draft.csv`는 portfolio % 기준** (`target_portfolio.csv`와 동일).

## 3. 생성 파이프라인

```text
current target (kr_alpha)
        ↓
exit_review: Replace → remove + 후보 1종 add
exit_review: Trim   → target × 0.7 (min_weight floor)
        ↓
normalize → kr_alpha 행 합 = kr_alpha_weight
        ↓
target_draft.csv + target_changes + replace_pairs
```

---

## 4. Replace 규칙

**조건**: `action_suggested` = Replace (Hard/Soft 승격)

**후보 선택** (`alpha_candidates`, `config/target_matrix.yaml`):

1. 등급 ≥ B
2. 아직 draft에 없는 ticker
3. **다른 섹터** 우선 (쏠림 완화)
4. `rank` / `composite_score` 최상위

**1 Exit → 1 Candidate** (max 5 pairs/run)

**예**

| Exit | Candidate | 이유 |
|------|-----------|------|
| 002380 KCC | 006040 동원산업 | Reject → B dividend_value |
| 192400 쿠쿠 | (후보 없으면 WARN) | |

---

## 5. Trim 규칙

**조건**: `action_suggested` = Trim

```text
new_target = max(min_weight, current_target × 0.7)
```

`matrix_action` = trim, `change_reason` = exit_reason

---

## 6. min / max 밴드

`config/target_matrix.yaml` → `bands`

| Tier | default sleeve | min ratio | max ratio | portfolio max |
|------|----------------|-----------|-----------|---------------|
| Core | 4% | 0.5 | 1.5 | 8% |
| Satellite | 3% | 0 | 1.25 | 5% |

---

## 7. 정규화 · 검증

### 7.1 Normalize

draft 행 `target_weight` 합 ≠ `kr_alpha_weight` 이면 **비례 스케일**.

허용 오차: ±0.5%p

### 7.2 Satellite cap

Satellite `sleeve_weight` 합 > **25%** → WARN (문서 v0.2)

### 7.3 단일 Satellite

sleeve > **5%** → max_weight cap
