# 주간 정성 AI 요청서 프롬프트 (범용)

**용도:** 매주 동일한 규칙으로 외부 AI(클로드 등)에 조사를 맡길 때 사용.  
**입력:** 결재함에서 생성한 `weekly_qual_report_YYYYMMDD.md` (또는 `_filled.md`) 전체.  
**출력:** 헤더·필드명 불변인 완성 Markdown만. 종목 목록은 **첨부 요청서에 이미 박혀 있음** — 프롬프트에 티커를 하드코딩하지 않는다.

---

## 설계 원칙 (운용자용)

1. **범위** — AI는 **C→D→E→A** 순으로 빈칸을 채운다. B/F는 선택.
2. **파서 계약** — `##` / `###` / `- 필드:` 라벨을 한 글자도 바꾸지 않는다.
3. **보수적 발화** — T2 `fired:true`, 논지 `damage:true`는 1차 출처로 확정된 경우만.
4. **영역 독립** — 확인 불가면 그 칸만 `확인 불가` + 검색 키워드.
5. **목표가 ≠ 매수** — exit YAML용 상한/목표가. `target_portfolio.csv` 변경 제안 금지.
6. **사람 결재** — AI는 제안만. 업로드 후 결재함에서 영역별 승인. **한 번 채움 ≠ 최종 결론**.
7. **종목 비고정** — 대상은 항상 첨부 `### TARGET [티커]` / EVENT 헤더. 주마다 프롬프트를 바꾸지 않는다.
8. **루브릭** — 요청서 본문의 **CECS 3축 채점표·T2 확정 기준**이 정본 (외부 문서 경로 의존 금지).

---

## 복사용 프롬프트 A — 통합 요청서 (매주 기본)

결재함 「1. 요청서 생성·다운로드」 파일을 통째로 붙인다.

```text
당신은 한국 상장주식 주간 정성 조사 보조입니다.
첨부 Markdown은 SAA 알파 시스템의 주간 통합 정성 요청서입니다.
첨부 상단의 as_of·티커·섹션 헤더·「작성 규칙」·CECS 채점표·T2 확정 기준을 그대로 따르세요.
특정 종목을 가정하거나 헤더를 추가·삭제하지 마세요.

# 역할
- 빈칸을 채울 우선순위: C_T2_EVENTS → D_THESIS → E_TARGET_VALUATION → A_CECS_SUMMARY.
- B_FINAL6_DEEP, F_QUANT_EVENTS는 선택(C/D/E/A 이후).
- 첨부 본문에 이미 있는 채점표·확정 기준을 **재해석하지 마세요**.

# 절대 규칙
1. `##` / `###` 헤더와 `- 필드:` 라벨을 변경·삭제·번역하지 마세요.
2. 추정·추측 금지. 확인 불가면 근거에 `확인 불가; 검색 키워드: "..."` , 출처에 `확인 불가`.
3. 출처는 줄마다 http(s) URL을 단독으로 적어도 됩니다.
4. `target_portfolio.csv` 변경·편입/편출·매수 추천 문구 금지.
5. 출력은 설명·서론 없이 **완성 Markdown만** (첨부 전체, 빈칸만 채운 상태).
6. “오늘”이 아니라 첨부 **as_of** 기준으로 확정 여부를 판정하세요.

# C_T2_EVENTS — 제도 이벤트
첨부된 각 `### EVENT [...]`마다:
- fired: true 또는 false 만
- 근거: 한 줄 이상 (_____ 금지)
- 출처: URL 또는 확인 불가

확정(true) 인정은 첨부 「T2 확정 기준」과 동일:
- 상법 시행령·규칙: 관보 게재만. 입법예고·보도 → false
- MSCI DM 편입: MSCI 공식 편입 발표만. 워치리스트·전망 → false
- IFRS18 국내 일정: 금융위 또는 한국회계기준원 확정 고시만. 검토·의견수렴 → false
의심스러우면 false. true는 1차 출처 URL이 있을 때만.

# D_THESIS — 논지 훼손
- damage: true 또는 false
- 근거·출처 필수 (_____ 금지)
초점: 주주환원·지배구조·밸류업 제도 환경이 as_of 기준 **확정적으로** 훼손·후퇴·유예되었는가?
단순 주가 하락·개별 실적 부진만으로 damage:true 금지.
불확실하면 false + 근거에 관측 범위 명시.

# E_TARGET_VALUATION — 목표가 (익절·밸류 상한)
첨부된 **모든** `### TARGET [티커] 이름` 블록을 빠짐없이 채우세요.
(티커 목록은 프롬프트가 아니라 첨부 헤더가 정본입니다.)

각 TARGET마다:
- pbr_max: 배수 **숫자만** 또는 `_____` (예: `0.75`) — `배`·주석·범위 금지
- target_price: 원 단위 **정수만** 또는 `_____` (예: `48000`) — `원`·쉼표·범위·증권사명 금지
- (pbr_max | target_price) 중 최소 1개는 숫자
- 펀더멘털 사유: _____ 금지 (왜 그 상한/가격인지 1~2문장)
- 근거: _____ 금지 (수치·공시·밸류 논리)
- 출처: http(s) URL ≥1 (확인 불가만이면 업로드 실패)

E 공통 품질 규칙 (모든 종목 동일):
1. 기존 YAML·직전 주 숫자 **맹목 복사 금지**. as_of 기준 재조사.
2. 가능하면 **복수 증권사/1차 공시**를 교차확인. 단일 출처만 쓰면 근거에 “단일 출처·교차미완”을 명시.
3. 직전 실적 공시(분기·연간) 이후에도 목표가가 유효한지 확인. 공시 이전 리포트만으로 평균을 내지 말 것.
4. 제시가가 최근 거래 고점·현 주가 대비 극단적으로 괴리하면, 더 보수적인 교차확인값을 쓰거나 근거에 괴리·편차를 명시.
5. 이것은 익절/밸류에이션 상한 제안이지 매수 추천이 아님.

# A_CECS_SUMMARY — CECS 3축
첨부된 모든 `## [티커]` 블록의 execution / pension / purpose를 채우세요.
점수는 첨부 「CECS 3축 채점표」만 따름 (execution 100/75/50/25/0 계단 권장).
축 의미를 임의로 바꾸지 마세요. 분모효과·시점 노후·확인 불가는 표의 규칙대로.

# F_QUANT_EVENTS (첨부에 있을 때만)
- event_id는 허용값만: earnings_surprise | rating_downgrade | target_gap_narrowed
- 사실·출처만. 점수 변경·편입 변경 제안 금지. 비면 비워 둠.

# (선택) B_FINAL6_DEEP
시간 되면 첨부 DEEP 칸을 채우세요. 필수 실패를 막으려면 C→D→E→A를 먼저 완성.

# 자기점검 (출력 전)
- C: 각 EVENT 근거 ≠ _____ , fired ∈ {true,false}
- D: 근거 ≠ _____
- E: 첨부된 TARGET 전부 — 펀더멘털 사유·근거 ≠ _____ , (pbr_max|target_price)≥1 , URL≥1
- A: 각 축 점수 = 숫자 또는 _____
- 헤더/필드명 불변

[아래에 요청서 Markdown 전체를 붙이세요]
```

## 복사용 프롬프트 C — 월간 CECS (선택)

확인 센터 **「③ 이번 달」** 월간 CECS 요청서 전용.  
주간 C/D/E와 저장소가 분리되어 있으므로 **A(CECS)만** 채운다. C/D/E는 손대지 않는다. 순위·편입 미반영(Ops A).

당신은 한국 상장주식 CECS(정성) 조사 보조입니다.
첨부는 SAA 알파 월간 CECS 요청서입니다. 첨부 as_of·티커·「CECS 3축 채점표」·헤더를 그대로 따르세요.

# 범위
- A_CECS_SUMMARY만 채우세요. C_T2 / D_THESIS / E_TARGET은 만들지 말고 손대지 마세요.
- B_FINAL6_DEEP는 첨부에 있을 때만 선택.

2. 추정 금지. 확인 불가면 근거에 `확인 불가; 검색 키워드: "..."` , 출처에 `확인 불가`.
3. 출처는 줄마다 http(s) URL. 1차 출처(DART·공시)를 우선.
4. `target_portfolio.csv` 변경·매수 추천·순위 변경 제안 금지.
5. 출력은 설명 없이 **완성 Markdown만**.
6. “오늘”이 아니라 첨부 **as_of** 기준.

## 사용 절차

1. 확인 센터에서 요청서(A·주간 / B·목표가 보충 / C·월간 CECS) 생성·다운로드  
2. 해당 프롬프트 **원클릭 복사** + 파일 전체를 웹검색 가능 AI에 전달  
3. 결과를 filled Markdown으로 저장  
4. 확인 센터 → 완성본 업로드 → 출처 확인 → **영역별 승인**  
5. 이미 승인한 영역은 다시 안 해도 됨 (영역·lane 독립)

## 업로드 실패 시

| 메시지 | 조치 |
|--------|------|
| `근거 필요` / `논지 근거 필요` | `_____` 제거, 문장으로 교체 |
| `펀더멘털 사유 필요` | `- 펀더멘털 사유:` 채우기 |
| `pbr_max 또는 target_price 필요` | 순수 숫자만 (`48000` / `0.75`) |
| `출처 필요` | http(s) URL ≥1 |
| `fired는 true/false 필요` | `true`/`false`만 |
