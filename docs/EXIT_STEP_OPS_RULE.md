# 익절 스텝 규칙 (Review-only) — 2026-07-19 채택

> 자동 주문·`target_portfolio.csv` 자동 변경 **없음**. UI 권고만.

## 배지

| 배지 | kind | 의미 |
|------|------|------|
| 유지 | `hold` | 미도달 |
| 줄이기 | `trim` | 근접 ≥70% · **¼(25%)** 한 스텝 |
| 환금 | `cash_half` | 목표가 도달 · **수량 절반(내림)** |
| 전량 | `exit_full` | 테제(S0) / 제안탈락(S2a) / 도달 후 N주 미상향(S2c) |
| 목표없음 | `missing` | exit YAML 부재 |

## 스텝

1. **S0** 논지·하드 → 전량  
2. **S2a** 제안 탈락(실보유가 제안에 없음) → 전량  
3. **S2c** 도달 상태 + `approved_as_of` 기준 **N주**(기본 4) 미갱신 → 전량  
4. **S1** 현재가≥목표가 또는 PBR≥pbr_max → **환금 절반**  
5. **S근접** 70%≤근접&lt;100% → 줄이기 25%  
6. 그 외 유지  

`defaults.exit_time_cap_weeks` in `data/kr_alpha_exit_targets.yaml`.
