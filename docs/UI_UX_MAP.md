## 읽는 순서 (포트)

1. **오늘 매매** — 팔기 → 유지 → 사기 (나침반 태도 한 줄 포함)  
2. **목표바** — 공격·방어·파킹 목표 100% (계좌 % 아님)  
3. **읽는 법** — 구성 / 운영 / 집합 / 나침반 / 주문 / 접기  
4. **집합 대조** — 둘 다=유지 · 제안만=사 · 보유만=팔  
5. **제안 카드** — 사도 됨 / 지금은 안 삼  
6. **단기·입력·심화** — 기본 접기 · 펼치면「이 칸 / 지금 / 무시」  

## 접기 규칙

- 제목 = **언제 펴는지** (SPEC·약어만 금지)  
- 본문 첫 블록 = **이 칸 · 지금 · 무시**  
- Soft ≠ 완충 · 결측 ≠ Soft 미달 · 파킹 ≠ 무위험 현금  

## 읽는 순서 (나침반)

1. **자산 움직임** — 개별주/단기채 · 숲 슬리브  
2. **알파로 넘기기** — 종목 매매는 포트 · ①팔 ②유지 ③사  
3. **왜 / 바젤 / 상품** — 근거·참고 (주문 아님)  

## 페이지 역할

| 페이지 | 역할 | 넣지 않음 |
|--------|------|-----------|
| 확인 | 정량·RSS·가동 | 제안 집행 UI |
| 포트 | 구성·오늘 매매·집합·카드 | 평단·실보유% 필수 · 전 재산 암시 |
| 나침반 | 거시 태도·수급 참고 | 알파 전량 공격 · 순위 재가중 |
| 백테스트 | 총수익·MDD·회전·비용 | 자동주문 |
