# 익절 표 용어 범례 추가 (경량)

> 배경: 보유 리뷰·Gap 표의 FUND/VAL/근접도/신호강도/trim_source_tag 등 용어가 설명 없이 노출되어 혼동됨(오늘 채팅에서 여러 차례 재질문 발생). 표 위/아래에 짧은 범례 고정.
> 원칙: **표시 텍스트 추가만.** 계산 로직 변경 없음.

## 1. 범위

### A. 알파 → 보유 리뷰 → 「익절 신호강도」 표
`st.subheader("익절 신호강도 (읽기 전용)")` 캡션 아래, 표 위에 `st.caption` 또는 `st.expander("용어 설명")`로 아래 내용 고정 노출(항상 펼쳐진 캡션 권장 — 매번 클릭 안 해도 보이게):

```
FUND = 펀더멘털 조건(ROE·배당성향·자사주소각) — yaml에 정의한 조건 전부 만족해야 도달
VAL = 밸류에이션 조건(PBR 등) — 정의한 조건 중 하나만 넘어도 도달
근접도 = 현재값이 목표값의 몇 %까지 왔는지(거리 측정값, 예측·확률 아님). 100%면 도달
신호강도 = 도달한 뒤에만 계산되는 값(0~100) — 근접도와 다른 계산식, 계단식 부분익절 비율(10/20/30%)을 결정
exit_leg = 어느 조건이 도달했는지: NONE(둘 다 미도달) / FUND / VAL / BOTH
trim_source_tag "trim:score"는 이 익절엔진과 무관 — 기존 스코어 기반 보유 리뷰 태그. 실제 트림 검토 여부는 action_state 확인
FUND만 설정된 종목 = 실적 개선만 기준(가격 상한 없음). VAL만 설정된 종목 = 가격 상한만 기준(실적 개선 기대 없음). 둘 다 설정 = 먼저 도달하는 쪽이 트리거
```

### B. 종합 포트 → Gap 표 「익절상태」 컬럼
표 위에 짧은 캡션 1줄만 추가(상세 설명은 A에 있으므로 링크/안내만):
```
익절상태 = 목표 미설정 / 미도달(근접도%) / 도달(FUND·VAL·BOTH) — 상세 설명은 알파 → 보유 리뷰 참고
```

## 2. 절대 금지
- 계산 로직(`take_profit_thesis.py`, `alpha_signal_board.py`, Gap 계산) 변경 없음
- 범례 텍스트에 "확률"/"승률" 등 금지어 사용 금지
- 이 범례를 신규 버튼/입력 요소로 만들지 않음 — 순수 안내 텍스트

## 3. 검증 요청
1. 보유 리뷰 탭에서 표 보기 전에(펼치지 않아도) 범례가 바로 보이는지
2. Gap 표에도 짧은 안내 캡션이 붙었는지
3. 범례 문구가 위 원문과 일치하는지 (용어 누락 없는지: FUND, VAL, 근접도, 신호강도, exit_leg, trim_source_tag, FUND/VAL 단독 설정의 의미)
