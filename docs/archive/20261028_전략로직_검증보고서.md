### 1.1 성공 정의 (`V3_CHARTER` · `strategy_portfolio.yaml`)

| | 베타 포트(앱 밖) | 이 알파 스크리너 |
|--|------------------|-----------------|
| 역할 | **주엔진** · 시장 수익 | **위성** · 품질·방어·파킹 |
| 목적 | 베타·성장 추종 | Soft 통과만 편입 · 미집행=단기채 · 낙폭·추격 억제 |

### 1.2 알파북 100% 분해 (코드)

```text
E = equity_pct (자세, 예: 80)
C = cash_pct   (예: 20) → KODEX 단기채권PLUS (214980)

중기 자리 = E × 0.90   → 예: 72%
단기 자리 = E × 0.10   → 예: 8%
방어      = C          → 예: 20%

공격(주식) = 오늘 Soft 통과 종목 weight 합
잔여        = 100 − 공격
  그중 min(잔여, C) = 방어
  나머지            = 파킹(동일 단기채)   ← Soft 공집합·미집행
```

구현: `alpha_system/ui/services/alpha_envelope_board.py`.

### 1.3 중기 vs 단기

| | 중기 Core | 단기 위성 |
|--|-----------|-----------|
| 점수 | Q·V·SR·R (`score_m` **가중 0**) | 위성 재랭크 + **score_m 하한** |
| Soft | QVM·게이트·하케다카·목표가 | **60·120 이평 + score_m≥70** |
| 익절 | 혼합 목표가 · 트레일 L1 | 정당P/B 미사용 · 120 이탈 축소 등 |
| 보유 | 장부 CSV 분리 | 장부 CSV 분리 |

## 3. 로직 레이어 검증

### 3.1 중기 선정

```text
factor_score_total = 0.35×Q + 0.30×V + 0.25×SR + 0.10×R
total_score       = 1.0×factor + 0.0×CECS
```

- 게이트: OpenDART·하케다카·현재가≥혼합 목표가 → **제안 제외**(다음 적격 채움).
- **의도적 결과:** 모멘텀(M)이 약해도 Q/V가 세면 편입 가능 → **가치함정 체감**과 구조적으로 맞닿음.

### 3.2 단기 선정

- `evaluate_short_trend_entry`: SMA60·120 위 + `score_m` ≥ 하한(기본 70).
- 실패 시 `proposal_eligible=False` · 대기 목록 · **비중 0**.

### 3.3 익절·축소 (직접 행동)

| 조건 | 할 일 |
|------|--------|
| 테제·논지 붕괴 | **전량 매도** |
| 제안 탈락(보유만) | **전량 매도** |
| 목표가 도달 | **절반 매도** → N주 미상향 시 **전량 매도** |
| 고점 −12% / −20% / −28% | **¼ / 절반 / 전량 매도** |
| L3 급락 | **¼~절반 매도** (전량 강제 아님) |

근거: `EXIT_STEP_OPS_RULE` · `TRAIL_EXIT_REVIEW_SPEC` · 코드 `ops_exit_signal` / `trail_exit_signal`.

### 3.4 매수

- 제안만 · Soft 통과 · **하루 ≤33%**(종목자리=100).
- Soft FAIL·이평 부족 → **추가 매수 금지**.

## 5. 전략 적합성 (수익 목표 기준)

운영자 목표: **수익창출**.

| 기대 | 이 프로그램 | 판정 |
|------|-------------|------|
| 가계 = 베타(대부분) + 알파(소수) | 차터 전제 | **적합** |
| 알파 Soft 통과분만 사고, 목표가·트레일에서 **팔아 실현** | 로직 일치 | **적합** |
| 알파만으로 코스피 이기기 | 비목적 | **부적합** |
| 중기 = 앞으로 모멘텀·급등 | M 제외 · 현재 M 약함 | **부적합** |
| 단기 Soft  debout 없이 급등 사냥 | Soft 0이면 파킹 | **부적합** |
| 가치함정 자동 면역 | Q/V 편향 → 함정 **가능** · 탈출은 **매도 규칙** | **부분** |

### 가치함정

- **구조적 노출:** 중기 Core가 M을 빼서 “싸·품질” 쪽 편향.
- **피하기:** Soft·게이트 탈락·목표가 이상 → **사지 마**.
- **탈출:** 제안 탈락·테제 붕괴·목표가·트레일 → **절반/전량 매도** (평단 낮추기 금지).
