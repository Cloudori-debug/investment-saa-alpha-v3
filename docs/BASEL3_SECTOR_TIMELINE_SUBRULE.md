## 0. 한 줄 결론

예. **방향(자본하한↑ · 완충자본 · 생산적 금융 병행)** 은 시계열로 예견 가능하고,  
**수혜 섹터도 단계마다 바뀌는 것이 정상**이다.  
다만 날짜는 **목표 시점 ±오차**로만 다루고, **목표 6개월 전(T−6M)** 부터 선진입·관찰만 허용한다.  
지금은 **테마 시계열 레이어**이며 Core QVM에 섞지 않는다.

## 1. 운영 원칙

| ID | 원칙 |
|----|------|
| P1 | **방향 Hard / 날짜 Soft** — “무엇을 강화하는가”는 고정에 가깝고, “언제 %가 오르는가”는 유예 가능 |
| P2 | **이중 시계** — (A) 규제 단계 시계 + (B) 당국 “생산적 금융” 예외·완화 시계. B가 A를 덮으면 수혜가 바뀜 |
| P3 | **선진입 = T−6M** — 목표 시행·상향의 **6개월 전**부터 워치·소형 관찰 편입만. 전량·Core 교체 금지 |
| P4 | **오차 밴드** — 목표일 ±3~6개월을 “정상 변동”. ±12개월 넘으면 단계 재라벨 |
| P5 | **QVM 상위** — 테마는 Review 가중·워치리스트만. `score_m`·순위 자동 가산 없음 |

## 3. 스테이지 → 수혜·부담 섹터 (선정 규칙)

### 3.1 선정 방법 (계산이 아니라 **매핑 규칙**)

1. 레버가 **자본비용↓ / 여신여력↑** 이면 → 직접 수혜 = **은행·은행지주** + 간접 = **그 여신이 가는 차주 섹터**  
2. 레버가 **표준방법 RW 영향↑ (S4)** 이면 → 저RW 자산 선호 = **주담대·국공채·우량대기업** 관련; 고RW = **무등급 중소·중견·일부 프로젝트** 부담  
3. S5가 켜지면 2의 “고RW 부담” 중 **정책 지정 산업**만 예외적으로 수혜로 재분류  
4. 종목 후보는 섹터 풀에서 QVM·게이트·목표가 있는 것만 Review (자동 매수 금지)

### 3.2 스테이지별 섹터 표

| Stage | 1차 수혜 (직접) | 2차 수혜 (간접·여신) | 상대 부담 | 선진입 테마 코드 |
|-------|-----------------|----------------------|-----------|------------------|
| S0 | 은행·지주 (BIS 개선) | 중소·소상공인 관련 경기민감·내수 | — | `BX_SME_CREDIT` |
| S1 | 자본여유 큰 **대형 은행지주** | 우량 대기업 금융 | IRB 혜택 크던 은행·공격여신 | `BX_LARGE_BANK` |
| S2 | 분산 여신·중소형 포트 은행 | — | 거액 단일 차주·대기업 편중 여신 | `BX_LEX_LIMIT` |
| S3 | CET1 두꺼운 지주 (배당 안정 테마는 제한적) | — | 자본 얇은 은행 · 고배당 기대상향 | `BX_BUFFER_CAP` |
| S4a↑ | 은행 중 **표준 RWA 관리·담보대출 비중** 테마 | **주담대·우량담보·고신용 대기업** | **무등급 중소·중견**, 일부 PF·프로젝트 | `BX_FLOOR_UP` |
| S4b | 동상 + 자본확충·자사주·배당 재조정 테마 | 저위험 자산 선호 지속 | 중소여신 위축 리스크 정점 | `BX_FLOOR_FINAL` |
| S5 | 정책 지정 **첨단·제조·벤처·생산적** | 해당 섹터 대출·투자 | S4만 보면 부담이던 쪽 중 지정분만 완화 | `BX_PROD_FIN` |

**한국 업종 매핑(워치 풀 예시, 확정 유니버스 아님)**

| 테마 코드 | 워치 섹터(예시) |
|-----------|-----------------|
| `BX_SME_CREDIT` | 은행, 저축은행·캐피탈(선택), 내수소비·중소형 경기민감 |
| `BX_LARGE_BANK` | 대형 은행지주 |
| `BX_FLOOR_UP` / `FINAL` | 은행지주, **보험(일부)**, 주택금융·리츠·우량건설(담보·주담 연동, 규제 교차주의), 우량 지주·유틸리티 |
| `BX_PROD_FIN` | 당국 발표 목록 우선 — 반도체장비·2차전지·방산·로봇·바이오 등 **발표 문장에 묶인 것만** |

## 4. 시계열 (목표 · 오차 · T−6M 선진입)

날짜는 **목표(T0)** 이며 Soft.  
**선진입 창 = [T0−6M, T0+오차상한]** 에서 관찰·Review만.

| Phase | 연결 Stage | 목표 T0 (중심) | 오차 밴드 | 선진입 시작 (T−6M) | 주 테마 | 비고 |
|-------|------------|----------------|-----------|---------------------|---------|------|
| Ph0 | S0 | 2020-06 | 기시행 | — | `BX_SME_CREDIT` | 학습·백테스트용 |
| Ph1 | S1 | 2023-01 | ±6M | — | `BX_LARGE_BANK` | 기시행 |
| Ph2 | S2 | 2024-01 | ±6M | — | `BX_LEX_LIMIT` | 기시행 |
| Ph3 | S3 | 2024-12 ~ 2025-H2 | ±6~12M | T0−6M | `BX_BUFFER_CAP` | 도입·강화 진행 |
| Ph4 | S4a (k↑ 65%대) | **유동** (보도상 2026~27축) | **±6~12M** | **T0−6M** | `BX_FLOOR_UP` | **현재 핵심 시계** |
| Ph5 | S4a (k↑ 70%대) | Ph4 T0 + 12M | ±6~12M | T0−6M | `BX_FLOOR_UP` | Ph4 확정 후 재앵커 |
| Ph6 | S4b 최종 72.5% | **2028-01-01** | ±6M (유예 시 +12M까지) | **2027-07-01** | `BX_FLOOR_FINAL` | 국제·국내 합의축 |
| Ph7 | S5 | 상시·발표 시점 | 발표 ±3M | 발표−6M 또는 예고일 | `BX_PROD_FIN` | A와 충돌 시 **재가중** |

### 4.1 Ph4 앵커 규칙 (날짜 Soft의 실무)

언론의 65%/70% 연도가 갈리므로:

1. **앵커 이벤트** = 금감원·금융위 “자본하한 k% 적용” **공식 문장** 또는 은행 사업보고서 “적용 비율”  
2. 앵커가 잡히면 Ph4 T0 = 그 분기말(또는 명시일), Ph5 = T0+12M  
3. 앵커 전: T0를 **“다음 공식 상향이 예상되는 최근 보도 중심 ±12M”** 로만 표시하고 **전량 베팅 금지**

### 4.2 선진입 서브규정 (T−6M)

| 규칙 | 내용 |
|------|------|
| E1 | 선진입 대상 = 해당 Phase **주 테마 코드** 워치 풀 ∩ (적격·목표가 있는 종목만) |
| E2 | 비중 상한(테마 합) **포트 제안 북의 관측용** — 예: Review 노트상 **≤ 알파 예산의 한 슬리브 내부 소수** (숫자는 추후 캘리브; 지금은 **Core 자동 편입 0**) |
| E3 | 진입 트리거 = (T≤T0−6M) ∧ (P6 증거 1+) ∧ (모멘텀 상방 가드 선택) |
| E4 | **감축·철회** = (T0+오차상한 경과 ∧ 레버 미확인) ∨ (S5가 테마를 무력화) ∨ (은행 CET1·RWA 공시가 테마와 반대) |
| E5 | 익절·논지·제안탈락 규칙은 **기존 EXIT/포트 바늘이 상위** — 본 시계열보다 우선 |
