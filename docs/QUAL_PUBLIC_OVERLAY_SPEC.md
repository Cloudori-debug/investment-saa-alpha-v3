## 운영 규칙

1. 홈「다음 할 일」은 **정량·컷오프·제안 북**이 우선. 주간 C/D/E는 **필수 게이트 아님**.
2. T2 `true` / 논지 `damage` — **화이트리스트 1차 URL**만. 보도·워치리스트·증권사 노트 단독 금지.
3. 익절 YAML 신규 승인 — **실측 앵커**(BPS·trailing PBR·52주)만. 증권사 단독 근거는 **거부**.
4. 기존 증권사 기반 YAML — 일괄 삭제 없음. 의심·보유·제안 종목만 재승인.
5. CECS·pension/purpose — 스킵 유지 ([`REAL_INVEST_SCOPE_CHECKLIST.md`](REAL_INVEST_SCOPE_CHECKLIST.md)).
6. 정성 기록 형식: 출처 URL + 한 줄 결론 + 행동(유지/축소/보류). **total_score 재혼합 금지.**
