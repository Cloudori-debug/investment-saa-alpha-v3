# domestic_beta 후보 집중도 재검토 (실행 명세서)

> SPEC 계열: [`KR_ALPHA_HYBRID_TRANSITION_SPEC.md`](KR_ALPHA_HYBRID_TRANSITION_SPEC.md) / [`KR_ALPHA_HYBRID_TRANSITION_RESULT.md`](KR_ALPHA_HYBRID_TRANSITION_RESULT.md) §2.2·§4 후속.
> 원칙: 이 스펙은 **조사·제안까지만**. `target_portfolio.csv` 등 실제 파일 변경 금지.

## 0. 배경 — 원장이 제기한 문제

RESULT §4에서 `069500`(KODEX 200)을 domestic_beta 신규 슬리브(6.87%)로 제안했음. 원장 지적: **코스피200은 시가총액가중이라 삼성전자·SK하이닉스 비중이 매우 커서, 이 ETF를 담는 것이 사실상 반도체 집중 베팅과 다르지 않다.** "국내 베타 분산"이라는 원래 취지와 어긋날 수 있음 — 실제 집중도를 확인하고 대안을 조사할 것.

## 1. 조사 항목

1. **069500(또는 226490 등 후보) 최신 상위 10종목 비중** — 삼성전자·SK하이닉스 합산 비중이 실제로 몇 %인지 실측(가능한 소스: 운용사 공시 PDF/월간보고서, 지수산출기관 공개자료 등). 정확한 실시간 값을 못 구하면 최근 공개된 근사치라도 출처와 함께 제시.
2. **저집중 대안 존재 여부 조사**:
   - 동일가중형 코리아 지수 ETF(예: 코스피100·200 동일가중 방식)가 국내 상장 ETF로 존재하는지.
   - 섹터 상한(캡)이 걸린 코리아 지수 상품 존재 여부.
   - 존재한다면 20일 평균 거래대금이 `min_20d_avg_trading_value_krw=1,500,000,000`(15억) 통과하는지 확인.
3. **226490(KODEX 코스피, RESULT §2.2에서 이미 후보로 언급됨)의 상위종목 비중도 069500과 비교** — "종목 수가 많다고 집중도가 실제로 낮아지는지" 검증(가설: 시총가중이라 큰 차이 없을 가능성 있음 — 확인 필요).
4. **domestic_beta를 아예 신설하지 않는 대안**의 수치 시뮬레이션: freed 6.87%p를 069500 대신 161510/279530(배당 ETF)에 추가 배분했을 때 §4 배분표를 다시 계산하고, 그 경우 삼성전자/SK하이닉스 룩스루 비중이 어떻게 달라지는지 비교(배당 지수는 통상 반도체 비중이 낮다는 가설 — 실제 161510/279530 구성종목에서 삼성전자·SK하이닉스 비중도 함께 확인).

- 시나리오 A(RESULT 원안): domestic_beta=069500 6.87%
