## 3. C 동결 스펙 (현행 v3)

재현·백테스트 시 **아래를 바꾸지 않음**.

| 축 | 고정값 |
|----|--------|
| 시장 | KOSPI (코스닥은 별도 장부 · 본 검증 1차는 KOSPI) |
| 자세 | `strategy_portfolio` E80/C20 (`soft_neutral_e80`) |
| 중기/단기 자리 | 개별주 안 90/10 → 중기≈72 · 단기≈8 · 방어 20 |
| 중기 점수 | `0.35Q+0.30V+0.25SR+0.10R` · CECS 0 · **M=0** |
| 중기 편입 | Soft·게이트 통과분만 · 통과 N종에 **중기 자리 균등** (N=3이면 ≈24%×3) |
| 단기 | 60/120 + `score_m` 하한 · 미통과·일봉부족 → **사지 않음** · 자리 파킹 |
| 매도 | L0 목표가 스텝 + L1 트레일(12/20/28) · 제안 탈락 시 전량 매도 규칙 |
| 리밸 | **월 Review-only** · 자동주문·`target` 기입 없음 |
| 수급 | 순위 재가중 **금지** |

**주의:** 24%는 “종목당 24% 정책”이 아니라 **N=3일 때 균등 결과**. 비교 시 N·캡을 명시.

## 4. KPI (세 층 · 모두 보고)

비용 = 증권거래세·농특세 골격 + 수수료·스프레드·슬리피지 가정(문서화).

| 층 | 필수 지표 |
|----|-----------|
| **알파북 단독** | CAGR · KOSPI200(배당포함) 대비 초과 · 샤프 · MDD · **연 회전율** · **비용차감 순** · 최대 종목/업종 비중 |
| **베타(가정 벤치)** | 동일 구간 벤치 CAGR·MDD (가계 합산용) |
| **가계 합산** | 총수익률 · MDD · 위험조정 · (선택) 알파 기여분 = 합산 − 베타만 |

추가:

- **교체율** (월·연) — Soft≠완충 검증용  
- **결측율** — Soft 미달 vs 일봉/데이터 부족 **분리 집계**  
- 단순 방어 대안: **전액 단기채** 또는 **E80을 단기채만** 대비 알파북 MDD/샤프

성공(채택) 초안: 표본외에서 **A 대비** 비용차감 위험조정 개선 **또는** (초과수익 없어도) 단순 단기채 방어 대비 **가계 MDD·샤프 개선이 재현**되고 회전이 폭주하지 않음.  
실패: 최종 미사용 구간에서 개선 미재현 · 또는 집중만으로 A보다 MDD 악화·비용 잠식.

## 5. 데이터·재현 규칙

1. **시점 정합:** 재무·공시는 당시 알 수 있는 정보만 (look-ahead 금지).  
2. **상장폐지·거래정지·액면·배당** 반영.  
3. **시간 분리 예:** 개발 구간 / 검증 구간 / **최종 미사용 테스트** · 테스트 보고 파라미터 재튜닝 시 새 미사용 구간 필요.  
4. **재현(우선순위 1):** 특정 as-of의 점수·편입·목표바·보유 집합을 동일 재구성 가능한지.  
5. 코드·YAML·스냅샷 해시/경로를 결과 옆에 기록.

구현 힌트: 기존 Shadow / mid·short Lab / `proposal_price_replay` 를 C 재현에 우선 사용 · A/B는 동일 유니버스·비용 엔진 공유.

## 7. UI·운영 메모 (검증과 병행 가능)

상세 수락표: [`V3_UI_UX_VERIFY.md`](V3_UI_UX_VERIFY.md) §6–7 (KPI↔화면 · U1–U16).
