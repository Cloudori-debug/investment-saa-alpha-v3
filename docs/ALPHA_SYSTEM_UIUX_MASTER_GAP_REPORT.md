## §6 검수 — 구현 측 자가판정

1. 열기→읽기→처리 화면 이동 없이: **구현됨** (처리 패널)
2. 폰 첫 화면 액션 큐: **레이아웃상 상단** — 폰 실기 확인 필요
3. 아직 아니다 / 판단 불가 구분: **판정 문장+ muted** — 실기 확인
4. 계층·박스 중첩: **개선됨** — 폰에서 확장 소속 확인
5. 가격/비중 바 축 분리: **기존 유지** + 회귀 테스트
6. 마찰 비대칭: **기존 go-live/T2/논지** 유지
7. 경고색≠모름: **PRE_LAUNCH·T3 상세 수정**
8. 한 손 조작: **실기 확인**
